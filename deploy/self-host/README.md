# Self-hosted OHSMS (this machine only)

This package runs one company on the computer it is unpacked on. It is not
the shared WEEHS suite and it does not talk to Firebase. Postgres, Keycloak,
and MinIO are real services with named volumes. The app host serves the
built SPA and stores files in MinIO.

Ports are published on `127.0.0.1` only. Do not add a tunnel, change DNS, or
publish these ports on another interface.

## Prerequisites

- Apple Silicon or another arm64 machine, or amd64 (the pinned images are
  multi-arch)
- Docker Desktop with Compose v2
- Node.js 22, used once to generate secret files
- Network access for the first `docker compose up`, so the images and npm
  dependencies can be fetched
- No host Postgres is required

## Secret file contract

Create the directory and the one password you will type at the Keycloak
login. Choose it yourself. Do not copy a password out of this document.

```sh
mkdir -p secrets
umask 077
touch secrets/bootstrap-password
chmod 600 secrets/bootstrap-password
```

`secrets/bootstrap-password` is mode `0600`, one line, at least 12
characters, no quotes. That line is the password for the person named as
the contact email on the registration form. It is also the only password
you type. Service passwords are generated by the next command and are not
printed.

```sh
node bootstrap.mjs
```

That writes, and will not overwrite if you run it again:

| File | What it is |
| --- | --- |
| `secrets/postgres-password` | Postgres role `ohsms` |
| `secrets/minio-root-password` | MinIO root password. The user name is `ohsms` |
| `secrets/keycloak-admin-password` | Keycloak admin console (`admin`) |
| `secrets/session-secret` | Signs the app session |
| `secrets/data-key-master` | This company's data-key master |
| `secrets/control-token` | Operator token. The browser does not receive it |
| `secrets/compose.env` | The three service passwords, for Compose |

Do not `cat`, log, or commit these files. `docker compose config` prints
them. Do not paste that output anywhere.

## Start, status, stop

From this directory:

```sh
docker compose up -d --build
docker compose ps
docker compose stop
```

`stop` does not delete volumes. Start again with `docker compose up -d`.
Do not run `docker compose down -v`.

## URLs (this machine)

| | |
| --- | --- |
| App | http://127.0.0.1:8787 |
| Register | http://127.0.0.1:8787/register-org |
| Keycloak (IdP and its admin console) | http://127.0.0.1:8080 |
| MinIO API | http://127.0.0.1:9000 |
| MinIO console | http://127.0.0.1:9001 |
| Postgres | 127.0.0.1:5432, database `ohsms`, user `ohsms` |

The registration form is filled with the running issuer
`http://127.0.0.1:8080/realms/ohsms`, client id `ohsms`, bucket `ohsms`,
and presign `http://127.0.0.1:8787/presign`. Those are the services this
compose file started. The IdP certificate and the database URL stay on the
server. The form does not ask for them.

## Register and sign in

1. Open http://127.0.0.1:8787/register-org and choose your own database.
2. Confirm the issuer, client id, bucket, and presign URL already shown.
   They must be the loopback addresses above.
3. Use a real contact email. That email becomes the Keycloak user. The
   password is the line in `secrets/bootstrap-password`.
4. Submit. The host fulfills against its own Postgres. The page shows
   http://127.0.0.1:8787 when the organization is live.
5. Sign in. The browser goes to Keycloak. The app session is not enough
   for a second visit: sign-out sends a SAML logout to Keycloak and the
   next sign-in sets `ForceAuthn`, so Keycloak asks again.

## Check persistence

```sh
docker compose stop
docker compose up -d
```

Sign in again. The organization, its records, and an uploaded file are
still there. MinIO and Postgres use named volumes `miniodata` and `pgdata`.

## What this package does not do

The archive was packed without Docker on the build machine, so the compose
file has not been started there. Image tags, the MinIO `mc ready` check, and
the Keycloak `/dev/tcp` check are unverified. If a service stays unhealthy,
`docker compose logs <service>` is the next step. The app process retries
Postgres, MinIO, and Keycloak for about three minutes on its own, and it
does not print passwords when a retry fails. Image pulls and the browser
recording happen on the machine where you run the commands above.
There is no public hostname until you choose one yourself. Do not point
this stack at the shared Firebase project.
